# 💻 Projeto FrontEnd

## 📚 Projeto de Desenvolvimento Web

Este projeto foi desenvolvido como parte das atividades da disciplina de FrontEnd, utilizando tecnologias de desenvolvimento web para criar páginas organizadas, responsivas e visualmente consistentes.

O projeto apresenta diferentes páginas e recursos desenvolvidos com **HTML5, CSS3 e Bootstrap 5**.

---

## 🎯 Objetivo

O objetivo deste projeto é desenvolver e aprimorar conhecimentos em desenvolvimento de interfaces web, utilizando boas práticas de estruturação, estilização e responsividade.

Nesta etapa, o projeto foi atualizado com o framework **Bootstrap 5**, buscando melhorar a organização visual e a adaptação das páginas para diferentes tamanhos de tela.

---

## 🛠️ Tecnologias utilizadas

As principais tecnologias utilizadas no projeto são:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git
- GitHub
